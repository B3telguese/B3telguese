## 🚀 Featured projects

### 🌿 Kuching Air Quality Prediction

A final-year research project exploring **Bayesian optimization for feature selection and hyperparameter tuning** in PM2.5 prediction. It includes Random Forest, XGBoost, CatBoost, SVR, a stacking ensemble, and a Flask dashboard for inspecting predictions and AQI categories.

**Explore:** research notebook, report, datasets, dashboard source, and saved model artifacts.  
**Technologies:** Python · Flask · scikit-learn · XGBoost · CatBoost · Jupyter

[View the project →](https://github.com/B3telguese/FYP-AirQuality-Kuching)

### 🌍 GeoLearn

An academic group project: a native Android geography-learning app with **flashcards, trivia quizzes, flag guessing, bookmarks, and progress screens**. The repository includes application source and Firebase setup guidance.

**Explore:** Android screens, learning activities, authentication, and data integration.  
**Technologies:** Java · Android · XML · Firebase Authentication · Cloud Firestore
